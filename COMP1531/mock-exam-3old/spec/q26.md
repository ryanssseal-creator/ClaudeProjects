# Q26. Problem Solving (10 marks)

This question is designed to assess your base JavaScript knowledge.

## Task

Complete the functions in `q26/assorted.js` to answer all of the following:

- `sumBy`: adds up the values stored under a given key across an array of objects. (2 marks)
- `partition`: splits an array into two arrays, depending on whether each element passes a test function. (3 marks)
- `mergeCounts`: combines two objects of numeric counts into a new object, adding the values of keys they share. (2 marks)
- `isAnagram`: decides whether two strings are made of exactly the same letters, ignoring case and spaces. (3 marks)

The full behaviour of each function is described in its header comment. None of the functions may modify their inputs.

- tests: `npm run test`
