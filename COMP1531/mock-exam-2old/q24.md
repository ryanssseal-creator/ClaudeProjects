a) Why it happens:
- This happens because the global variable gets reinitialised to empty once the server ends. All the data within that variable gets lost upon resetting it.

b) Solution:
- To save the data on a cloud database, that retrieves and sends data to a cloud service, so that data is saved.

c) Advantage and disadvantage of saving on every change:
- Advantage: Changes are instantaneous, and are applied the moment that function is called. So if a request was made, the user can freely exit the program right after that.
- Disadvantage: This will heavily reduce the efficiency of the program, as every request will send data frequently, slowing down the program for the user.
