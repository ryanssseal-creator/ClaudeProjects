# Q28. Enrolment (6 marks)

Every term, thousands of students submit enrolment requests in the first hour that enrolment opens. Before a request can be timetabled, it has to pass some basic checks: the request must be complete, the student and course identifiers must be well formed, and students can only overload with approval.

You have been asked to automate the validation of enrolment requests so that only valid requests are passed on for timetabling.

## Task

Complete the function in `q28/enrolment.ts`, based on the function header comments and the interface below.

- You should NOT modify function prototypes or parameters. You can validate this by checking all provided tests pass.

## Interface

**`validateEnrolment(enrolment)`** validates an enrolment request against specific criteria.

Parameters: `enrolment` - the enrolment request to validate.

The checks are made **in the order listed**. The first check that fails throws an `Error` with the EXACT message shown.

| # | Thrown error (EXACT message) | When |
|---|---|---|
| 1 | `"Incomplete enrolment. Missing field/s: '<missing field>', '<another missing field>'."` | Any of the `request` fields are missing on the enrolment object. Fields are comma-separated and listed in alphabetical order, e.g. `"Incomplete enrolment. Missing field/s: 'courses', 'term'."` |
| 2 | `"zID '<zid>' is invalid."` | The zID is not the letter `z` followed by exactly 7 digits |
| 3 | `"Term '<term>' does not exist."` | The term is not 1, 2 or 3 |
| 4 | `"No courses selected."` | The courses array is empty |
| 5 | `"Course code '<code>' is invalid."` | A course code is not exactly 4 upper-case letters followed by 4 digits. If several are invalid, report the first one in the array. |
| 6 | `"Enrolling in '<number of courses>' courses requires overload approval."` | There are more than 3 courses and overload has not been approved |

On success, return the string:

```
"Enrolment valid. Proceed to timetable."
```

Note: a field is *missing* only if it is not on the object at all. A field that is present with the value `0`, `false` or `[]` is not missing.
