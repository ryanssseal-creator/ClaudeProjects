# Q31. Textbook Exchange (10 marks)

Sick of paying full price for textbooks they open twice, students have asked Arc to run a second-hand textbook exchange. Arc's developers have started on an API but have run out of time, and so the rest of the design has fallen to you.

The existing API allows users to sign in, and allows sellers to list a textbook and anyone to view listings.

## Existing API

### `POST /auth/login`

Authenticates a student, returning a unique session token.

- **Body**: `{ "zid": "z1234567", "password": "hunter42" }`
- **200**: `{ "session": "a complex and secure session token" }`
- **400**: `INVALID_CREDENTIALS` zID and zPass combination fails to authenticate with UNSW single-sign-on.

### `POST /listings`

List a textbook for sale. The logged-in student becomes the seller.

- **Header**: `session`
- **Body**: `{ "title": "Actuarial Mathematics", "courseCode": "ACTL1101", "price": 45 }`
- **200**: `{ "listingId": 1234 }`
- **400**: `INVALID_TITLE` Title is empty or longer than 100 characters. `INVALID_PRICE` Price is negative.
- **401**: `UNAUTHORISED` Session is empty or invalid.

### `GET /listings`

Returns a list of all listings.

- **Header**: `session`
- **200**: `[ { "listingId": 1234, "title": "Actuarial Mathematics", "courseCode": "ACTL1101", "price": 45, "sellerZid": "z1234567", "status": "AVAILABLE" } ]` (status is `AVAILABLE` or `SOLD`)
- **401**: `UNAUTHORISED` Session is empty or invalid.

### `GET /listing/{listingId}`

Get information about one listing.

- **Path**: `listingId`
- **Header**: `session`
- **200**: `{ "listingId": 1234, "title": "Actuarial Mathematics", "courseCode": "ACTL1101", "price": 45, "sellerZid": "z1234567", "status": "AVAILABLE" }`
- **401**: `UNAUTHORISED` Session is empty or invalid.

All error responses have the body `{ "error": "ERROR_TYPE", "message": "A helpful and descriptive error message" }`.

However, the API is still missing functionality for buyers to find the books they need and make offers, and for sellers to respond to those offers.

## User stories

Arc interviewed students and created the following user stories:

1. As a buyer, I want to filter listings by course code and by maximum price so that I only see books I need and can afford.
2. As a buyer, I want to make an offer on a listing so that the seller knows I am interested and what I am willing to pay.
3. As a buyer, I want to withdraw an offer I have made so that I am not committed to a book I no longer need.
4. As a seller, I want to see all the offers on one of my listings so that I can choose between them.
5. As a seller, I want to accept an offer so that the listing is marked as sold to that buyer.
6. As a user, I want the system to prevent invalid operations, including making an offer on my own listing or on a sold listing, and viewing or accepting offers on a listing that is not mine.
