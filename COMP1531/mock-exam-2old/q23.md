a) Black-box / white-box:
- My tests are black-box, the teammate suggestion is white-box.

b) Two reasons:
- They are the better choice because the tests will not know the way the functions are implemented, and strictly rely on how they 'should' behave from the specification. This allows for the tests to be more accurate in following the specification, whilst also isolating the function implementation during testing.

c) One thing HTTP tests alone cannot tell you:
- Whether or not your function implementation is correctly following the spec.
