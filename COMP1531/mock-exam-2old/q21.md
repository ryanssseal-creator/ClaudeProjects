a) Acceptance criterion 1:
- The system shall have a method to export a file into the CSV when given
the request to do so, unless the data is unable to be properly formatted
in CSV format.

Acceptance criterion 2:
- The system should adequately present the data in a clean, readable fashion.

b) Functional requirement:
- A user should be able to search for a specific name if necessary.

Non-functional requirement:
- The export should be provided such that the data can be uploaded efficiently onto the results system.
