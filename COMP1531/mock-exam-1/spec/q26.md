# Q26. Problem Solving (10 marks)

This question is designed to assess your base JavaScript knowledge.

## Task

Complete the functions in `q26/assorted.js` to answer all of the following:

- `unique`: returns a new array with duplicate elements removed, keeping the first occurrence of each. (2 marks)
- `countOccurrences`: returns an object that maps each element of an array to the number of times it appears. (3 marks)
- `pick`: creates a copy of an object containing only the specified keys. (2 marks)
- `reverseWords`: reverses the letters of every word in a string, keeping the words in the same order. (3 marks)

The full behaviour of each function is described in its header comment. None of the functions may modify their inputs.

## Marking

- tests: `npm run test`
