# Q30. Cinema (10 marks)

You've just started an internship at a company that builds ticketing software for cinemas. Your team has inherited the pricing code, which is old, has been patched by many people, and has no tests. Your manager has asked you to write tests for the `ticketPrice` function in `q30/cinema.ts`. This function decides how much a customer pays for a ticket based on who they are and which session they are attending.

## Task

Your task is to write tests to cover the given program.

## Part 1 - Basic Coverage (7 marks)

In `q30/cinema.test.ts`:

- Write tests for the `ticketPrice` function.
- Your goal is to achieve 100% statement, branch, function and line coverage in `cinema.ts`.

Notes:

- You may only make 1 function call per test.
- You can assume that the implementation is correct when writing your tests.
- Your test clarity/design will not be assessed. We are only assessing coverage.

### Testing

You can use the following command to run the tests and generate a coverage report:

```
npm run test-unit
```

## Part 2 - HTTP Coverage (3 marks)

In `q30/server.test.ts`:

- Write HTTP tests for the `/cinema/price` route in `q30/server.ts`.
- Your goal is to achieve 100% statement coverage in `cinema.ts` and `server.ts`.

Notes:

- You can assume that the implementation is correct when writing your tests.
- Your test clarity/design will not be assessed. We are only assessing coverage.

Hint: consider how you might use part 1 of this question.

### Testing

You can run the following command to start the server with a coverage report
(the report is printed when you stop the server with Ctrl+C):

```
npm run start-coverage
```

You can use the following command to run your http tests:

```
npm run test-server
```

## Submission

Only `q30/cinema.test.ts` and `q30/server.test.ts` are collected. All other files are replaced in automarking.
