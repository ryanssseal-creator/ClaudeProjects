# Q31. CSE Gym (10 Marks)

Tired of paying for memberships they never use, COMP1531 tutors are opening a small gym in the basement of K17 that runs group fitness classes. True to form, they refuse to use any existing booking software, and so the design of this system has fallen to you.

The tutors have already defined a basic API which allows users to sign in and view classes, and allows trainers to create classes.

## Existing API

### `POST /auth/login`

Authenticates a user of the gym, returning a unique session token and their role in the system.

- **Body**: `{ "zid": "z1234567", "password": "hunter42" }`
- **200**: `{ "session": "a complex and secure session token", "role": "MEMBER" }` (role is `MEMBER` or `TRAINER`)
- **400**: `INVALID_CREDENTIALS` zID and zPass combination fails to authenticate with UNSW single-sign-on.

### `POST /classes`

Create a new fitness class.

- **Header**: `session`
- **Body**: `{ "name": "Spin", "startTime": "2026-11-20T07:00", "capacity": 12 }`
- **200**: `{ "classId": 1234 }`
- **400**: `INVALID_NAME` Name is empty or longer than 50 characters. `INVALID_CAPACITY` Capacity is less than 1.
- **401**: `UNAUTHORISED` Session is empty or invalid.
- **403**: `FORBIDDEN` Session corresponds to a user whose role is not `TRAINER`.

### `GET /classes`

Returns a list of all upcoming classes.

- **Header**: `session`
- **200**: `[ { "classId": 1234, "name": "Spin", "startTime": "2026-11-20T07:00", "capacity": 12, "spotsLeft": 3 } ]`
- **401**: `UNAUTHORISED` Session is empty or invalid.

### `GET /class/{classId}`

Get information about one class.

- **Path**: `classId`
- **Header**: `session`
- **200**: `{ "classId": 1234, "name": "Spin", "startTime": "2026-11-20T07:00", "capacity": 12, "spotsLeft": 3 }`
- **401**: `UNAUTHORISED` Session is empty or invalid.

All error responses have the body `{ "error": "ERROR_TYPE", "message": "A helpful and descriptive error message" }`.

However, the API is still missing functionality for members to book, cancel and search for classes.

## User stories

The tutors interviewed stakeholders and created the following user stories:

1. As a member, I want to be able to book a spot in a class so that I am guaranteed a place.
2. As a member, I want to be able to cancel my booking so that someone else can take my spot.
3. As a member, I want to search for classes based on keywords so that I can find classes I am interested in.
4. As a member, I want the system to prevent me from performing invalid operations, including booking classes that are full and cancelling bookings which I did not make.
5. As a trainer, I want to ensure all users of the gym are UNSW students or staff so that the equipment is treated well.
