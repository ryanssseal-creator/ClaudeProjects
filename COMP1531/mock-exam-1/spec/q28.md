# Q28. Parcel (6 marks)

A courier company receives thousands of parcel bookings each day. Before a parcel can be dispatched, it must pass key criteria such as a maximum weight, a maximum declared value, a verified address and paid postage.

You have been asked to automate the validation of parcel bookings to ensure that only valid parcels are passed on for dispatch.

## Task

Complete the function in `q28/parcel.ts`, based on the function header comments and the interface below.

- You should NOT modify function prototypes or parameters. You can validate this by checking all provided tests pass.

## Interface

**`validateParcel(parcel)`** validates a parcel booking against specific criteria.

Parameters: `parcel` - the parcel booking to validate.

| Thrown error (with EXACT message) | When |
|---|---|
| `"Parcel is overweight."` | The parcel weighs more than 22 kg |
| `"Declared value of '<declaredValue>' too high."` | The declared value is more than $5,000 |
| `"Provided trackingId '<trackingId>' not in range."` | The tracking id is not 8 digits |
| `"Incomplete parcel. Missing field/s; '<missing field>', '<another missing field>'."` | Any of the `details` fields are missing on the parcel object. Fields are comma-separated and listed in alphabetical order, e.g. `"Incomplete parcel. Missing field/s; 'declaredValue', 'weightKg'."` |

On success, return the string:

```
"Parcel in correct format. Proceed to dispatch."
```
