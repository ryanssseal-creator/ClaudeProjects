# Q30. Library Loans (10 marks)

You've just started an internship in the team that maintains the UNSW Library's systems. Your team has inherited the code that decides whether a loan is allowed. It is old, has been patched by many people, and has no tests. Your manager has asked you to write tests for the `loanService` function in `q30/loans.ts`. This function decides whether a member may borrow an item and, if so, for how many days.

## Task

Your task is to write tests to cover the given program.

## Part 1 - Basic Coverage (7 marks)

In `q30/loans.test.ts`:

- Write tests for the `loanService` function.
- Your goal is to achieve 100% statement, branch, function and line coverage in `loans.ts`.

Notes:

- You may only make 1 function call per test.
- You can assume that the implementation is correct when writing your tests.
- Your test clarity/design will not be assessed. We are only assessing coverage.

### Testing

You can use the following command to run the tests and generate a coverage report:

```
npm run test-unit
```

## Part 2 - HTTP Coverage (3 marks)

In `q30/server.test.ts`:

- Write HTTP tests for the `/library/loan` route in `q30/server.ts`.
- Your goal is to achieve 100% statement coverage in `loans.ts` and `server.ts`.

Notes:

- You can assume that the implementation is correct when writing your tests.
- Your test clarity/design will not be assessed. We are only assessing coverage.

Hint: consider how you might use part 1 of this question.

### Testing

You can run the following command to start the server with a coverage report
(the report is printed when you stop the server with Ctrl+C):

```
npm run start-coverage
```

You can use the following command to run your http tests:

```
npm run test-server
```

## Submission

Only `q30/loans.test.ts` and `q30/server.test.ts` are collected. All other files are replaced in automarking.
