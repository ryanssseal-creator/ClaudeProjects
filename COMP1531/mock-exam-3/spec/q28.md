# Q28. Driving Test (6 marks)

Service NSW receives many applications for driving tests each day. Before a test can be booked, an application must pass key criteria such as a minimum age, enough logbook hours, a passed eyesight test and a paid fee.

You have been asked to automate the validation of applications to ensure that only eligible learners are passed on for booking.

## Task

Complete the function in `q28/licence.ts`, based on the function header comments and the interface below.

- You should NOT modify function prototypes or parameters. You can validate this by checking all provided tests pass.

## Interface

**`validateApplication(application)`** validates a driving test application against specific criteria.

Parameters: `application` - the application to validate.

| Thrown error (with EXACT message) | When |
|---|---|
| `"Learner is underage."` | The learner is younger than 17 years old |
| `"Logbook hours of '<logbookHours>' insufficient."` | The learner has logged fewer than 120 hours |
| `"Provided applicationId '<applicationId>' not in range."` | The application id is not 6 digits |
| `"Incomplete application. Missing field/s; '<missing field>', '<another missing field>'."` | Any of the `requirements` fields are missing on the application object. Fields are comma-separated and listed in alphabetical order, e.g. `"Incomplete application. Missing field/s; 'age', 'logbookHours'."` |

On success, return the string:

```
"Application in correct format. Proceed to booking."
```
