# Q29. Plant Nursery (14 Marks)

At Yuchao's Plant Nursery, keeping the price list up-to-date is a full-time job. The team wants an application that lets them easily add new plants and adjust prices, so every customer sees the right plant at the right price. As a fan of the nursery, you've volunteered to create the application to help the team.

The backend functions have already been written for you in `q29/plants.ts`.

## Task

In `q29/server.ts`, implement the routes specified in the interface below.

Every error response has the body `{ "error": "ERROR_NAME", "message": "..." }`, exactly as returned by the backend function.

## Interface

### `DELETE /clear`

Clear all plants. (Already implemented.)

- **200**: `{}`

### `POST /plant/add`

Add a new plant.

- **Body**: `{ "name": "Monstera", "size": "Small", "price": 25 }`
- **200**: `{ "plantId": 0 }`
- **400**: `INVALID_PLANT_NAME`, `INVALID_PLANT_PRICE`, `INVALID_PLANT`

### `GET /plant/filter`

Filter plants by price: returns the plants priced at or below the given price, in ascending order of price.

- **Query**: `price` (number), e.g. `/plant/filter?price=30`
- **200**: `{ "plants": [ { "name": "Monstera", "size": "Small", "price": 25 } ] }`
- **400**: `INVALID_PLANT_PRICE`

### `GET /plant/list`

Get a list of plants by ids, in the order the ids were given.

- **Query**: `plantIds` (string of comma-separated numbers), e.g. `/plant/list?plantIds=2,0,1`
- **200**: `{ "plants": [ { "name": "Monstera", "size": "Small", "price": 25 } ] }`
- **400**: `INVALID_PLANT_ID`

### `PUT /plant/{plantid}`

Update the price of a plant by id.

- **Path**: `plantid` (number)
- **Header**: `role` (string)
- **Body**: `{ "price": 30 }`
- **200**: `{}`
- **400**: `INVALID_PLANT_ID`, `INVALID_PLANT_PRICE`
- **403**: `INVALID_ROLE`

### `PUT /plant/all`

Bulk update all plant prices by taking `discountAmount` off each.

- **Header**: `role` (string)
- **Body**: `{ "discountAmount": 5 }`
- **200**: `{}`
- **400**: `INVALID_DISCOUNT_AMOUNT`
- **403**: `INVALID_ROLE`
