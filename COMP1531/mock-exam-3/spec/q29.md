# Q29. Shared Notes (14 marks)

Your project group keeps its meeting notes in a group chat, where they are lost within the hour. You've decided to build a small shared notes service: anyone in the group can read the notes, but only the people trusted to edit can create, pin or delete them.

The backend functions have already been written for you in `q29/notes.ts`. Read them: their parameters, return values and error names tell you most of what you need.

## Task

In `q29/server.ts`, implement the routes specified in the interface below.

Every error response has the body `{ "error": "ERROR_NAME", "message": "..." }`, exactly as returned by the backend function.

## API keys

Every route except `/clear` requires an API key, sent in a header named `apikey`. There are two valid keys:

| Key | Can do |
|---|---|
| `viewer-key-123` | Read notes only |
| `editor-key-456` | Read and change notes |

The backend checks the key for you and returns one of two errors, which apply to **every** route that takes a key:

- **401** `UNAUTHORISED`: the key is missing or is not one of the valid keys.
- **403** `FORBIDDEN`: the key is valid, but it is not allowed to perform this operation.

## Interface

### `DELETE /clear`

Clear all notes. (Already implemented.)

- **200**: `{}`

### `POST /note`

Create a new, unpinned note. Editor only.

- **Header**: `apikey`
- **Body**: `{ "title": "Sprint 3 retro", "body": "Start the tests earlier." }`
- **200**: `{ "noteId": 0 }`
- **400**: `INVALID_TITLE`, `INVALID_BODY`
- **401**: `UNAUTHORISED`
- **403**: `FORBIDDEN`

### `GET /notes`

List notes (without their bodies), in the order they were created.

- **Header**: `apikey`
- **Query**: `pinned` (`true` or `false`), e.g. `/notes?pinned=true`. If `true`, only pinned notes are returned. If `false` or not given, all notes are returned.
- **200**: `{ "notes": [ { "noteId": 0, "title": "Sprint 3 retro", "pinned": false } ] }`
- **401**: `UNAUTHORISED`

### `GET /note/stats`

Count the notes.

- **Header**: `apikey`
- **200**: `{ "total": 3, "pinned": 1 }`
- **401**: `UNAUTHORISED`

### `GET /note/{noteid}`

Get one full note.

- **Path**: `noteid` (number)
- **Header**: `apikey`
- **200**: `{ "note": { "noteId": 0, "title": "Sprint 3 retro", "body": "Start the tests earlier.", "pinned": false } }`
- **400**: `INVALID_NOTE_ID`
- **401**: `UNAUTHORISED`

### `PUT /note/{noteid}/pin`

Pin or unpin a note. Editor only.

- **Path**: `noteid` (number)
- **Header**: `apikey`
- **Body**: `{ "pinned": true }`
- **200**: `{}`
- **400**: `INVALID_NOTE_ID`, `INVALID_PINNED`
- **401**: `UNAUTHORISED`
- **403**: `FORBIDDEN`

### `DELETE /note/{noteid}`

Delete a note. Editor only.

- **Path**: `noteid` (number)
- **Header**: `apikey`
- **200**: `{}`
- **400**: `INVALID_NOTE_ID`
- **401**: `UNAUTHORISED`
- **403**: `FORBIDDEN`
