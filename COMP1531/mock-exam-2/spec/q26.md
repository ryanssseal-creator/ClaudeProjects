# Q26. Problem Solving (10 marks)

This question is designed to assess your base JavaScript knowledge.

## Task

Complete the functions in `q26/assorted.js` to answer all of the following:

- `intersection`: returns an array of the elements that exist in both input arrays. (2 marks)
- `rotate`: returns a copy of an array with its elements shifted to the right by a given number of positions, wrapping around. (3 marks)
- `invert`: creates a new object where the keys and values of the original are swapped. (2 marks)
- `toCamelCase`: converts a string of space-separated words into camelCase. (3 marks)

The full behaviour of each function is described in its header comment. None of the functions may modify their inputs.

## Marking

- tests: `npm run test`
