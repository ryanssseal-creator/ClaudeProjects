# Q26. Problem Solving (10 marks)

This question is designed to assess your base JavaScript knowledge.

## Task

Complete the functions in `q26/assorted.js` to answer all of the following:

- Returns an array containing the elements that exist in both input arrays. (2 marks)
- Flattens an array of arrays into a single array. (3 marks)
- Creates a copy of an object with its keys and values swapped. (2 marks)
- Returns the initials of the words in a string. (3 marks)

## Marking

When you think your program is working, you can run some simple automated checks:

- tests: `npm run test`

## Submission

Only `q26/assorted.js` is collected. All other files are replaced in automarking.
