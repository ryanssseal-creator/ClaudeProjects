# Exam Information

**COMP1531 Mock Exam 2**, written in the style of the 26T3 practice exam.
This is unofficial study material, not a UNSW paper.

## Conditions

Sit it the way the real one runs, or the mark means nothing:

- **10 minutes reading, 3 hours working.** Set a timer.
- **100 marks.** The real exam has a 40% hurdle.
- **Turn off Copilot / AI autocomplete in VS Code** and don't open Claude Code until you are finished.
- Don't open `solutions/` until you've been marked.

## Exam technique

- **Never leave a question blank.** A half-working Q29 with two routes still scores. An empty Q31 scores zero.
- **A file that doesn't compile scores zero for the whole question.** Before moving on, run the tests once so you know the file at least loads.
- Do the questions in whatever order gets you marks fastest. Q31 needs no code at all.
