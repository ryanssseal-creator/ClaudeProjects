# Q31. Textbook Exchange (10 Marks)

Sick of paying full price for textbooks they open twice, students have asked Arc to run a second-hand textbook exchange. Arc's developers have started on an API but have run out of time, and so the rest of the design has fallen to you.

The existing API allows users to sign in, and allows sellers to list a textbook and anyone to view listings.

## Existing API

### `POST /auth/login`

Authenticates a student, returning a unique session token.

- **Body**: `{ "zid": "z1234567", "password": "hunter42" }`
- **200**: `{ "session": "a complex and secure session token" }`
- **400**: `INVALID_CREDENTIALS` zID and zPass combination fails to authenticate with UNSW single-sign-on.

### `POST /listings`

List a textbook for sale. The logged-in student becomes the seller.

- **Header**: `session`
- **Body**: `{ "title": "Actuarial Mathematics", "courseCode": "ACTL1101", "price": 45 }`
- **200**: `{ "listingId": 1234 }`
- **400**: `INVALID_TITLE` Title is empty or longer than 100 characters. `INVALID_PRICE` Price is negative.
- **401**: `UNAUTHORISED` Session is empty or invalid.

### `GET /listings`

Returns a list of all listings.

- **Header**: `session`
- **200**: `[ { "listingId": 1234, "title": "Actuarial Mathematics", "courseCode": "ACTL1101", "price": 45, "reserved": false } ]`
- **401**: `UNAUTHORISED` Session is empty or invalid.

### `GET /listing/{listingId}`

Get information about one listing.

- **Path**: `listingId`
- **Header**: `session`
- **200**: `{ "listingId": 1234, "title": "Actuarial Mathematics", "courseCode": "ACTL1101", "price": 45, "reserved": false }`
- **401**: `UNAUTHORISED` Session is empty or invalid.

All error responses have the body `{ "error": "ERROR_TYPE", "message": "A helpful and descriptive error message" }`.

However, the API is still missing functionality for students to reserve, un-reserve and search for textbooks.

## User stories

Arc interviewed students and created the following user stories:

1. As a student, I want to be able to reserve a textbook so that nobody else buys it before I can pick it up.
2. As a student, I want to be able to cancel my reservation so that the textbook is available to other students.
3. As a student, I want to search for textbooks based on keywords so that I can find the books for my courses.
4. As a student, I want the system to prevent me from performing invalid operations, including reserving textbooks that are already reserved and cancelling reservations which I did not make.
5. As a seller, I want to ensure all users of the exchange are UNSW students so that I know who I am dealing with.
