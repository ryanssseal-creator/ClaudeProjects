# Q28. Enrolment (6 marks)

UNSW receives thousands of enrolment requests in the first hour that enrolment opens. Before a request can be timetabled, it must pass key criteria such as a maximum study load, a minimum WAM, paid fees and met prerequisites.

You have been asked to automate the validation of enrolment requests to ensure that only eligible students are passed on for timetabling.

## Task

Complete the function in `q28/enrolment.ts`, based on the function header comments and the interface below.

- You should NOT modify function prototypes or parameters. You can validate this by checking all provided tests pass.

## Interface

**`validateEnrolment(enrolment)`** validates an enrolment request against specific criteria.

Parameters: `enrolment` - the enrolment request to validate.

| Thrown error (with EXACT message) | When |
|---|---|
| `"Student is overloading."` | The student is enrolling in more than 18 units of credit (uoc) |
| `"WAM of '<wam>' insufficient."` | The student's WAM is less than 50 |
| `"Provided zid '<zid>' not in range."` | The zid is not 7 digits |
| `"Incomplete enrolment. Missing field/s; '<missing field>', '<another missing field>'."` | Any of the `request` fields are missing on the enrolment object. Fields are comma-separated and listed in alphabetical order, e.g. `"Incomplete enrolment. Missing field/s; 'uoc', 'wam'."` |

On success, return the string:

```
"Enrolment in correct format. Proceed to timetable."
```
