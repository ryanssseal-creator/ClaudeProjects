# Q29. Bookshop (14 Marks)

At Hayden's Second-Hand Books, keeping track of what's on the shelves is a full-time job. The team wants an application that lets them easily add new books and adjust how many copies they have, so every customer can find out what's in stock. As a regular at the shop, you've volunteered to create the application to help the team.

The backend functions have already been written for you in `q29/books.ts`.

## Task

In `q29/server.ts`, implement the routes specified in the interface below.

Every error response has the body `{ "error": "ERROR_NAME", "message": "..." }`, exactly as returned by the backend function.

## Interface

### `DELETE /clear`

Clear all books. (Already implemented.)

- **200**: `{}`

### `POST /book/add`

Add a new book.

- **Body**: `{ "title": "Dune", "genre": "Fiction", "copies": 3 }`
- **200**: `{ "bookId": 0 }`
- **400**: `INVALID_BOOK_TITLE`, `INVALID_COPIES`, `INVALID_BOOK`

### `GET /book/filter`

Filter books by genre, in descending order of copies.

- **Query**: `genre` (string), e.g. `/book/filter?genre=Fiction`
- **200**: `{ "books": [ { "title": "Dune", "genre": "Fiction", "copies": 3 } ] }`
- **400**: `INVALID_GENRE`

### `GET /book/list`

Get a list of books by ids, in the order the ids were given.

- **Query**: `bookIds` (string of comma-separated numbers), e.g. `/book/list?bookIds=2,0,1`
- **200**: `{ "books": [ { "title": "Dune", "genre": "Fiction", "copies": 3 } ] }`
- **400**: `INVALID_BOOK_ID`

### `PUT /book/{bookid}`

Update the number of copies of a book by id.

- **Path**: `bookid` (number)
- **Header**: `role` (string)
- **Body**: `{ "copies": 5 }`
- **200**: `{}`
- **400**: `INVALID_BOOK_ID`, `INVALID_COPIES`
- **403**: `INVALID_ROLE`

### `PUT /book/all`

Bulk update all books by adding `extraCopies` to each.

- **Header**: `role` (string)
- **Body**: `{ "extraCopies": 2 }`
- **200**: `{}`
- **400**: `INVALID_EXTRA_COPIES`
- **403**: `INVALID_ROLE`
