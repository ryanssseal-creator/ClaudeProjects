# Q29. Lost and Found (14 marks)

The security desk in the Main Library has a cardboard box full of lost property and a paper logbook nobody can read. They want an application where staff can log found items, students can search for and claim their belongings, and security can clear out items once they've been collected. You've volunteered to build the server.

The backend functions have already been written for you in `q29/lostFound.ts`. Read them: their parameters, return values and error names tell you most of what you need.

## Task

In `q29/server.ts`, implement the routes specified in the interface below.

Every error response has the body `{ "error": "ERROR_NAME", "message": "..." }`, exactly as returned by the backend function.

## Interface

### `DELETE /clear`

Clear all items. (Already implemented.)

- **200**: `{}`

### `POST /item`

Report a newly found item.

- **Body**: `{ "description": "Black umbrella", "location": "Library" }`
- **200**: `{ "itemId": 0 }`
- **400**: `INVALID_DESCRIPTION`, `INVALID_LOCATION`

### `GET /item/search`

Search unclaimed items whose description contains a keyword.

- **Query**: `keyword` (string), e.g. `/item/search?keyword=umbrella`
- **200**: `{ "items": [ { "itemId": 0, "description": "Black umbrella", "location": "Library", "claimedBy": null } ] }`
- **400**: `INVALID_KEYWORD`

### `GET /item/{itemid}`

Get a single item.

- **Path**: `itemid` (number)
- **200**: `{ "item": { "itemId": 0, "description": "Black umbrella", "location": "Library", "claimedBy": null } }`
- **400**: `INVALID_ITEM_ID`

### `PUT /item/{itemid}/claim`

Mark an item as claimed by a student.

- **Path**: `itemid` (number)
- **Body**: `{ "zid": "z5555555" }`
- **200**: `{}`
- **400**: `INVALID_ITEM_ID`, `INVALID_ZID`, `ALREADY_CLAIMED`

### `DELETE /item/claimed`

Remove every item that has been claimed.

- **Header**: `role` (string)
- **200**: `{ "removed": 2 }`
- **403**: `INVALID_ROLE`

### `DELETE /item/{itemid}`

Remove one item.

- **Path**: `itemid` (number)
- **Header**: `role` (string)
- **200**: `{}`
- **400**: `INVALID_ITEM_ID`
- **403**: `INVALID_ROLE`
